## 🌟 Key Features

- **Role-Based Dashboards**: Tailored views for Admins, Doctors, Pharmacists, Lab Technicians, Patients, and Receptionists.
- **AI Prescription Scanner**: Multimodal Gemini 3.6 Vision OCR that scans handwritten paper prescriptions directly via camera or upload and auto-populates drug dispensing forms.
- **AI Clinical Assistant & Symptom Triage**: Real-time diagnostic guidance powered by Gemini Flash.
- **EHR & Medical Records**: Digital patient charts, diagnosis history, and medical file attachments.
- **Appointments & Doctor Schedules**: Interactive booking system with real-time slot availability.
- **Pharmacy & Auto-Reorder Engine**: Batch tracking, stock alerts, rack locations, and automated reorders.
- **Laboratory Information System**: Test ordering, sample status tracking, and report generation.
- **Billing & Razorpay Payment Integration**: Instant invoice generation and online payments.

---

## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript, Tailwind CSS, Lucide Icons, GSAP
- **Backend**: Node.js, Express, esbuild
- **AI Integration**: `@google/genai` (Gemini 3.6 Flash Vision & Text)
- **Deployment**: Render Web Services (`render.yaml`)
